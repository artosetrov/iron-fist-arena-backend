Что изменилось

  • Награды как shop ItemCard — тот же визуальный компонент, что и в сетке магазина: тёмный фон, rarity border, арт + label-строка снизу. Единый язык.
  • Label-строка с монетой — как в товарах магазина (видно на скриншоте оружейной секции). Для наград показываем количество или «FREE».
  • Rarity border вокруг награды — сразу читается ценность: gold → legendary, potion → uncommon, XP → rare.
  • Badge ×N в углу арта — если количество >1 (потионов 3, XP 17 и т.д.), иначе просто арт.
  • Hero-pack art убран — награды сами рассказывают что внутри, лишняя иллюстрация съедала место.
  • Layout: Header (title/desc + ribbon/counter) → Rewards (3 shop-cards) → Footer (price stack + CLAIM). Высота ≈ 196pt.
  • Swift: в коде это будет `HStack { ForEach(offer.contents) { ItemCardView(context: .offerReward) } }` — переиспользуем существующий компонент из памяти itemcard_unified_refactor.
