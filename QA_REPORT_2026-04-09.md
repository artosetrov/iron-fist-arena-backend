## Найденные баги (11) — Все исправлены

### ✅ BUG-01 · CRITICAL — Battle result card buttons off-screen → FIXED
**Файл:** `BattleResultCardView.swift`
**Фикс:** Обёрнуто в ScrollView + maxHeight constraint

### ✅ BUG-02 · FALSE POSITIVE — Auth back buttons
**Статус:** Работают корректно, проблема была с точностью нажатия в симуляторе

### ✅ BUG-03 · HIGH — Stat labels truncated → FIXED
**Файл:** `HeroDetailView.swift`
**Фикс:** Добавлено `.minimumScaleFactor(0.7)` на stat names

### ✅ BUG-04 · MEDIUM — Login spacing → FIXED
**Файл:** `LoginView.swift`
**Фикс:** Spacing `spaceLG` → `spaceSM`

### ✅ BUG-05 · MEDIUM — Character creation stepper truncation → FIXED
**Файл:** `OnboardingDetailView.swift`
**Фикс:** `.lineLimit(1).minimumScaleFactor(0.7)` на step tab names

### ✅ BUG-06 · MEDIUM — Race description truncated → FIXED
**Файл:** `AppearanceStepView.swift`
**Фикс:** `.lineLimit(1)` → `.lineLimit(2)` для race description

### ✅ BUG-07 · MEDIUM — Hub building label clipping → FIXED
**Файл:** `CityMapView.swift`
**Фикс:** Label X clamped с 60px margin от краёв

### ✅ BUG-08 · MEDIUM — Opponent avatar shield fallback → FIXED
**Файл:** `AvatarImageView.swift`
**Фикс:** Fallback заменён на class-specific icon (characterClass.iconAsset)

### ✅ BUG-09 · LOW — Referral section infinite spinner → FIXED
**Файл:** `ReferralSectionView.swift`
**Фикс:** Добавлен `loadFailed` state с retry button

### ✅ BUG-10 · MEDIUM — Shop: internal item keys in Special Offers → FIXED
**Файл:** `ShopOffer.swift`
**Описание:** Отображалось "3x health_potion_large" вместо "3x Health Potion Large"
**Фикс:** Добавлена `displayName()` функция — замена `_` на пробелы + capitalization

### ✅ BUG-11 · LOW — Fortune Wheel: result modal text overflow → FIXED
**Файл:** `FortuneWheelDetailView.swift`
**Описание:** Текст результата "+X Gold (sector label)" мог переполнить модальное окно
**Фикс:** `.lineLimit(2).minimumScaleFactor(0.85).multilineTextAlignment(.center)`
