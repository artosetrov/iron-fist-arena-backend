Combat Screen — Proposals

Three proposals for the most important screen in the game. Each addresses the five flagged problems: duplicate stance echo, unclear ownership, detached timer, left-aligned STRIKE, and missing actives slot. See the full audit report for rationale.

Variant A

Vertical · Integrated STRIKE

Enemy on top, you on bottom — spatial ownership. Stance picker in the center with no duplicate readout. Timer fills the STRIKE button as it elapses. 2 active talents dock beside STRIKE.

Variant B

Hotbar · Side portraits

Keeps the current side-by-side portrait aesthetic. Stance picks overlay the portraits as gold/blue glyphs — no duplicate echo. Radial arc timer around STRIKE. 3-slot active hotbar on the left.

Variant C

Stance silhouette · Novel

Tap body parts on a shared silhouette — Attack mode flashes gold, Defend mode flashes blue, auto-flips after each pick. Enemy intent shown as ghost arrow on the same body. Most space-efficient, highest design risk.

Recommendation: start with Variant A — safest upgrade, proven pattern (Marvel Snap / HS / Raid), resolves every flagged problem without re-educating existing players.
