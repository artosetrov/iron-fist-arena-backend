01 — Проблема одинаковой высоты

Проблема: info-зона разная

  • Arena: Rating (1 число) + WR% (1 pill) = 2 строки
  • Boss: HP (1 число) + Drops (1 pill) = 2 строки
  • Hero: Rating + HP bar + STA bar = 3 строки
  • Если просто stack-fit → разная высота карточек в grid
  • Если truncate — контент обрезается

Решение: 3 фиксированных слота (72px)

  • Slot A (label, 16px): "PVP RATING" / "HP" / "RATING" — всегда одна строка
  • Slot B (value, 28px): главное число — всегда одна строка, крупно
  • Slot C (secondary, 28px): pills у арены/боссов; компактные bars у героев
  • Высота = 72px для всех без исключений
  • Hero bars компактнее (4px), но влезают в тот же slot C

✓ Верификация одинаковой высоты

Все карточки выше = одинаковая высота потому что: portrait height = width × 1.1 (aspect-ratio, одинаковый у всех) + info zone = 72px hard-coded (не зависит от контента). Hero bars помещаются в slot C потому что используют height:4px compact format вместо pills. В SwiftUI: portrait = .aspectRatio(1.0/1.1, contentMode:.fit), info zone = .frame(height: LayoutConstants.cardInfoHeight).

04 — Swift Constants (LayoutConstants.swift)

Новые константы в LayoutConstants.swift

// ── Character Card System ──────────────────────
static let cardPortraitRatio: CGFloat  = 1.0 / 1.1   // aspectRatio для portrait zone
static let cardInfoHeight: CGFloat     = 72           // FIXED info zone height (all contexts)
static let cardLvlBadgeSize: CGFloat   = 38           // LVL badge diameter (portrait card)
static let cardCornerRadius: CGFloat   = 14           // = arenaCardRadius (уже есть)

В SwiftUI portrait zone: .aspectRatio(LayoutConstants.cardPortraitRatio, contentMode: .fit)
Info zone: .frame(height: LayoutConstants.cardInfoHeight)
Это гарантирует одинаковую высоту без магических цифр в каждом компоненте.
