## Паттерны и уроки

### 1. Supabase revert-path completeness (Auth)

**Что произошло:** `upgrade-guest/route.ts` при откате (Prisma failure) восстанавливал только `user_metadata.is_guest`, оставляя Supabase-строку с новым email'ом, паролем и `email_confirm=true`. Аккаунт дрейфовал: guest-сессия видела старые credentials, Supabase — новые.

**Корень:** Первая версия revert-блока (2026-04-17) исправила только metadata. Разработчик написал полный revert спустя сутки после обнаружения.

**Fix (748f35d):** Revert-payload теперь содержит:
- `email` → оригинальный email гостя
- `password` → `crypto.randomUUID()` (инвалидирует новые credentials)
- `email_confirm` → `true` (сохраняет доступ к guest-аккаунту)

**Правило добавлено в oracle/SKILL.md §9c:** При `auth.admin.updateUserById` + downstream Prisma fail — revert обязан восстановить ВСЕ изменённые поля, не только metadata.

---

### 2. Granular role-gating в admin-панели

**Что произошло:** Любая роль, прошедшая `getAdminUser()` (включая `moderator`), могла мутировать balance config, items, seasons, skills, passives, dungeons. Moderators are view-only по замыслу.

**Fix (abf2066):** Добавлен `canModifyConfig(admin.role)` на все POST/PUT/PATCH/DELETE handlers 10 game-config маршрутов. GET-хэндлеры остаются открытыми для всех трёх ролей.

**Правило добавлено в oracle/SKILL.md §9d:** game-config write endpoints обязаны вызывать `canModifyConfig` после `getAdminUser`, иначе moderator получает доступ на запись.

---

### 3. Аналитика — новая архитектура (fire-and-forget)

**Что появилось (1f5d297):** Provider-agnostic аналитика. 7 критических funnel-events: `signup`, `first_pvp`, `iap_purchase`, `bp_claim`, `daily_login`, `level_up`, `shop_upgrade`.

**Паттерн:** generic analytics-вызовы задуманы серверно-авторитативными, fire-and-forget (`void` — не `await`), и должны вызываться ПОСЛЕ commit транзакции. Но в текущем repo этот слой пока остается typed scaffold без живых backend call-sites; реально активная instrumentation path сегодня — `tutorial-analytics.ts`. На iOS есть зеркальный scaffold `AnalyticsService.swift` с теми же 7 событиями, но он тоже пока не подключен к живым UI-flow call-sites. SDK (Firebase/Mixpanel) при необходимости подключается через `setAnalyticsBackend()` в одном месте.

**Правило добавлено в oracle/SKILL.md §10:** Никогда не awaiting analytics внутри транзакции — только после.

---

### 4. Auth local-row bootstrap (login/guest/me)

**Что появилось (c04d379, 8325c13):** Единый паттерн bootstrap-а местной User-строки для всех трёх read-surfaces (login, guest, /me). Если Supabase-токен валиден, но local User отсутствует — создаётся на месте с email-collision guard. Это решает dead-end "logged in but no character" после schema migrations.

**Архитектурно:** Этот паттерн теперь является стандартом для всех auth-маршрутов, которые читают Supabase-authenticated users.
