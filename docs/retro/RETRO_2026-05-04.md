## Паттерны и уроки

### 1. Optimistic cold-start как сложившийся архитектурный шаблон

`InteractiveBattleViewModel.init(attackerProfile:defenderProfile:)` + `FighterProfile.init(character:)/init(opponent:)` — третий крупный случай за ~3 недели, когда «paint cached shell, then refresh» полностью убирает loader-spike (раньше: profile cache, Arena prefetch, APIClient GET dedup; см. `project_phase2_responsiveness.md`). Сегодня заменены 3 HexPulseLoader-а одним bgPrimary placeholder + `ConnectingPillStrip` + `AvatarSkeletonFill`.

**Подтверждение, не правка:** правило `feedback_optimistic_ui_everywhere.md` уже работает. Mirror уже фиксирует «skeleton preferred over spinner». Никаких новых правил не требуется — паттерн закрепился.

### 2. Один канал обратной связи на одно событие (НОВОЕ)

`InteractiveRoundLogCard` выкинул `logList` ScrollView, потому что `DamagePopup`/`ActiveFireBanner`/`ConsumableFireBanner` уже доставляют per-event фидбек как floating VFX. Параллельный скроллируемый список тех же событий заставлял глаз выбирать, какой канал читать, и делал экран шумнее без новой информации.

Заодно дропнут заголовок «ROUND N · EXCHANGE» — номер раунда и так висит в `roundStrip` прямо над panel-ом.

**Действие:** в `mirror/SKILL.md` добавлена секция «One Feedback Channel Per Event (2026-05-04)» с отсылкой на коммит `4f0bf20`.

### 4. Verbal clarity вместо аббревиатур в боевом UI

Серия микро-копи-правок: `OFF/DEF/DODGE` → `Damage / Damage taken / Dodge chance`; `ATK CHEST / DEF CHEST` → `HIT CHEST / GUARD CHEST`. Это не code-rule, а UX-направление по combat v3.1. Принципиальный сигнал — «короткие коды читаются как новый язык, который игрок должен выучить; глаголы первого лица читаются мгновенно». Документировано в прототипе `combat-proto-v3.html`. Mirror-чеклист уже косвенно покрывает это через «First-session friendliness».
