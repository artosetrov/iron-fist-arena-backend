## Паттерны и уроки

### 1. Извлечение анимированных оверлеев в отдельные файлы

**Что:** `treasureOverlay()` (60 строк inline) → `TreasureRewardOverlay.swift` (140 строк standalone).

**Почему это правильно:** Оверлеи с локальным animation state (`@State private var modalScale`, `@State private var goldCount`, etc.) не могут жить как `@ViewBuilder` методы — им нужны собственные `@State` свойства. Inline-методы не могут иметь свой `@State`. Извлечение в отдельный View — единственный корректный путь.

**Как применять:** Когда оверлей/модал требует:
- Локальный `@State` для анимации
- `.onAppear` с хореографией (multi-phase animation)
- Собственную логику skip/dismiss
→ Извлекать в отдельный файл, не пытаться держать inline.

### 2. Accessibility на кнопках в модалах

**Что:** TreasureRewardOverlay изначально создан без `.accessibilityLabel()` на кнопке Continue. Обнаружено ретро-агентом.

**Почему:** При создании нового View с фокусом на анимации/UX легко забыть accessibility. Кнопки с `Text("CONTINUE")` кажутся "самоописывающими", но правила проекта требуют explicit `.accessibilityLabel()` на ВСЕХ кнопках.

**Как применять:** Checklist при создании нового View: (1) tokens verified, (2) `.compositingGroup()` after overlays, (3) `.accessibilityLabel()` on every Button, (4) pbxproj entries.

### 3. RewardBurstView + HapticManager.coinCascade — готовый reward toolkit

**Что:** Проект уже имеет полный набор для reward-анимаций:
- `RewardBurstView` с `.rewardBurst()` modifier — 8 стилей частиц
- `NumberTickUpView` / `NumberTickUpText` — animated counters
- `HapticManager.coinCascade(count:)` — каскадный тактильный feedback
- `SFX.chestOpen`, `.coinDrop` — звуковые эффекты
- `MotionConstants.springBouncy` — bounce spring presets

**Урок:** Перед написанием кастомной анимации — проверять существующие компоненты в `Views/Components/` и `Theme/`. В данном случае всё нужное уже было.
