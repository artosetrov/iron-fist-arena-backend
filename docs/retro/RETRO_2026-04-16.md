## Паттерны и уроки

### 1. (2c — Recurring Fix) Admin mutation state: всегда `finally`

**Что произошло:** В ходе wiki-аудита blocks 061-068 обнаружено, что в 10+ admin-страницах mutation handlers (`create`, `update`, `delete`) сбрасывали `isMutating` только на happy path. Любой thrown error от server action оставлял экран навсегда застрявшим в loading-состоянии.

**Root cause:** Паттерн `setIsMutating(true); await action(); setIsMutating(false)` без `try/catch/finally` — классический async mistake в React.

**Fix:** Wrapped все mutation handlers в `try/catch/finally` во всех затронутых admin-страницах.

**Rule added:** Oracle SKILL.md → Section 8 "Admin React Async State". Scanner-подсказка: `grep -rn "setIs[A-Z]"` в admin/src + проверка наличия `} finally {`.

---

### 2. (2c — Recurring Fix) iOS typed contracts: `[String: Any]` полностью устарел

**Что произошло:** 37 wiki-блоков (072-108) документировали и фиксировали систематическое удаление raw `[String: Any]` из всех iOS-сервисов. Паттерны `static func from(serverData: [String: Any])` убраны из `DungeonInfo`, `GoldMineSlotResponse`, всех Auth/Shop/Dungeon/Combat сервисов.

**Root cause:** Исторически iOS-слой писался с raw dict-парсингом до того, как APIClient получил `keyDecodingStrategy = .convertFromSnakeCase`.

**Fix:** Полная миграция — все API-контракты теперь typed Codable structs. `postRaw()` deprecated.

**Rule added:** Guardian SKILL.md — добавлено явное правило о запрете `[String: Any]` parsing helpers в service layer, со ссылкой на wiki blocks 072-108 как инцидент.

---

### 3. (2d — New Convention) Referral code normalization

**Что произошло:** `tutorial/referral/route.ts` теперь использует `getReferralLinkValues(characterId, code)` для поиска рефералов. Прямой `prisma.character.count({ where: { referredBy: code } })` пропускал исторические форматы (UUID, нормализованный код, legacy формат).

**New utility:** `getReferralLinkValues(characterId, code)` → массив всех valid lookup values. `normalizeReferralCode(code)` + `isReferralCodeLike(code)` для валидации.

**Rule:** При любом запросе к `referredBy` field в Prisma — использовать `{ in: getReferralLinkValues(...) }` а не direct equality.
