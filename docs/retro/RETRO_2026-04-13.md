## Уроки (signals)

### 🔁 Recurring manual fix — snake_case CodingKeys (x2 за день)

- `e25891c` (talents) и `4d757da` (Interactive Combat): оба раза добавили `enum CodingKeys: String, CodingKey { case x = "snake_name" }` и получили `keyNotFound` в рантайме.
- Причина: `APIClient.decoder.keyDecodingStrategy = .convertFromSnakeCase` уже конвертирует ключи; ручные CodingKeys дают **двойную конверсию** — декодер ищет `matchId` в уже сконвертированном словаре с ключом `matchId` → мисс.
- **Действие**:
  - Добавлено правило в `.skills/skills/guardian/SKILL.md` (секция Common Pitfalls).
  - Добавлен scanner check `## 8. snake_case CodingKeys in DTOs` в `check_design_system.sh` — ловит паттерн `case X = "snake_case"` в `Hexbound/Models/`.

### 🔧 Debug infrastructure pattern

- `e1bbf04` + `eea3b6b` — расширение APIError для surfacing field-level decode errors и server detail на 500. Полезный паттерн на будущее: когда debug-toast имеет только "что-то пошло не так", первым делом нужно расширить error envelope, а не гадать.
