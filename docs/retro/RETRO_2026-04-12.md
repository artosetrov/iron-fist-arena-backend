## Паттерны и уроки

### 1. Codable flip-flop на AppRoute (2 коммита подряд)

**Что произошло:** Убрали `Codable` с `AppRoute` в `e3b43f6`, потому что новый `.stash` case с associated values не мог автоматически синтезировать Codable. Через один коммит (`2b4a3ce`) пришлось вернуть — `NavigationPath.append()` требует Codable.

**Урок:** Любой `enum`, используемый с `NavigationPath`, ДОЛЖЕН быть `Codable`. При добавлении новых case'ов с associated values — нужно написать ручной `Codable` conformance, а не убирать протокол.

**Действие:** Нет обновления правил — это специфический Swift/SwiftUI факт. Но стоит помнить при добавлении новых route case'ов.

### 4. Масштабный QA-аудит: double-tap exploits как системный паттерн

**Что произошло:** QA нашёл 7 критических багов — 3 из них double-tap race conditions (Arena fight, Contraband claim, Shop buy). Паттерн один: guard-флаг ставится ПОСЛЕ начала async-операции, а не ДО.

**Корень:** `@Observable` ViewModels не имеют atomic guard pattern. Каждый новый async action пишется без проверки на double-tap.

**Урок:** Каждый `.task`/async action в ViewModel, который вызывает сетевой запрос, ДОЛЖЕН ставить guard-флаг (`isLoading`, `isClaiming`, etc.) как ПЕРВУЮ строку функции, ДО любого async work.

**Действие:** Это паттерн для guardian — добавить проверку на "guard before await".
