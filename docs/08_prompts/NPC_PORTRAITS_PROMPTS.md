# NPC portraits — one face per voice (2026-10-16)

Every voiced NPC speaker (`scripts/npc_voice/README.md` → Cast) has its own portrait. Before this, 44 hints and most guides showed the same goblin (`shopkeeper`) whatever voice was speaking.

- Family: the existing NPC look (`shopkeeper`, `lady-fortuna`, `npc-shell-master`) — hand-drawn ink + watercolour wash, characterful caricature; the boss family's grotesque is toned down for guides.
- Model: `nano_banana_2_1`, 1:1, 2k, thinking medium. Style anchors (Higgsfield media, imported from the repo's committed PNGs): merchant `7f4cda43-1682-48ee-8194-b710fdbf0f95`, fortuna `673d128d-5fc6-4059-962f-d0573b596526`, finch `a1e02219-1cd0-4fb9-8eb4-db16d0f52f19` (`image_references`). Canon characters put their own image first as an identity anchor.
- Key: green `#00FF00` for purple / red / violet subjects, magenta `#FF00FF` for green-skinned and blue ones.
- Ingest: raws downscaled to 1024 px, then `scripts/ingest_generated_sprite.py raw_<slug>.png npc-<slug> --pt 256 --key <hex> --out Hexbound/Hexbound/Resources/Assets.xcassets/NPC` (widget avatar is 256 pt, `LayoutConstants.npcAvatarSize`). Head crops `npc-<slug>-face` (`--pt 64`) feed the round avatars (mini button, hint bar, quest banner, tutorial bubble).
- Code: `NPCSpeaker` (`Persistence/NPCVoice.swift`) maps speaker slug → `portrait` / `face`; `NPCVoice.speaker(for:)` reads the speaker from the recording name, and `NPCGuideWidget` / `NPCSpeechBubble` show the voice's face for any recorded line. `NPCHint.npcImage` is derived from `npcName`.
