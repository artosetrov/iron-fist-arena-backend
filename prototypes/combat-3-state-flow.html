Combat 3-State Flow

Interactive prototype for the state-driven battle UI refactor. Open on desktop for the full frame; the middle pane is a 390×844 iPhone viewport.

Rules

1
One screen, one job.
2
Pickers only in CHOOSE. Never in RESOLVE.
3
Previous round info never bleeds into next CHOOSE.
4
STRIKE disabled until both ATK + DEF picked.
5
Enemy intent shown as lock, not "???"
6
Rewards above stats in END.
7
Opacity + width + translateY only. No scale.

Prototype Controls

Drive the state machine manually. Each button forces one clean transition — no layered leftovers.

States

C
CHOOSE — pickers interactive, STRIKE locked until both zones.
R
RESOLVE — read-only, damage floats on portraits, HP tweens.
E
END — rewards count up, stats below.

Flow tests

▶
Play round — runs a full CHOOSE → RESOLVE → back to CHOOSE cycle.
✖
Finishing blow — simulates HP→0, freeze frame, END.
V/D
Switch END between Victory and Defeat.

What to look for

·
No stale round card during CHOOSE.
·
No pickers during RESOLVE.
·
Damage numbers read before labels.
·
All animation is opacity / width / Y-translate only.
