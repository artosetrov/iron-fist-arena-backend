Talents — Horizontal Tree

Warrior class shown · prototype v1 · 2026-04-19

LAYOUT

  • 21:9 canvas (1400×600) scrolls horizontally inside phone screen.
  • Floating sticky HUD on top (tabs + SP + 4 active slots) — Hub-style chrome.
  • Background theme per class: Warrior = mountain pass, Mage = arcane library, Rogue = shadows, Tank = fortress wall.
  • Bottom minimap shows scroll position across 3 tiers.
  • No scroll on vertical axis — nothing goes off screen vertically.

NODE MATH (20 nodes)

  • Foundation (6 common) — Vitality, Iron Skin, Wards, Crit Eye, Cooldown, Lifesteal.
  • Specialization (9 class-specific) — 3 lanes × 3 nodes (Offense / Balanced / Defense).
  • Keystones (3) — build-defining effects at end of each lane.
  • Ultimates (2) — class-signature abilities, require 2 keystones unlocked.

SP ECONOMY

Ranks cost 1 / 2 / 3 SP (6 SP to max a node). 20 nodes × 6 SP = 120 SP to fully max — unachievable, forces choice.

  • Level 2–50: +1 SP per level = 49 SP
  • Milestones (10, 20, 30, 40, 50): +2 SP each = 10 SP
  • Prestige bonus: +5 SP per prestige, permanent
  • L50 P0 = 59 SP, L50 P5 = 84 SP

Milestone moments give "ladder climb" feel — not just a flat per-level trickle.

CLASS BUDGET

4 classes × 20 nodes = 80 node designs.
Common nodes reused across classes visually = 6 shared designs + 56 unique = 62 total designs.

REUSE

Existing PassiveNode schema supports: classRestriction, positionX/Y, tiers, connections, ranks via cost increment. No migration needed — just seed new data.
